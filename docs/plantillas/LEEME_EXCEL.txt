REGISTRO EXCEL OPERATIVO
========================

ARCHIVOS
--------
  registro_desayuno_operativo_ACTUALIZADA.xlsx  = Excel a rellenar e importar
  1_probar_conexion.cmd                         = conexion + dry-run (no guarda)
  2_importar_a_bm.cmd                           = import REAL a BM
  regenerar_plantilla.cmd                       = regenera plantilla (dev)

FLUJO
-----
1) Cerrar BM y Excel
2) Rellenar filas en la hoja Registro (y demas hojas si aplica) del ACTUALIZADA.xlsx
3) Guardar y cerrar Excel
4) 1_probar_conexion.cmd  -> CONECTADO / DRY-RUN OK o SKIP
5) 2_importar_a_bm.cmd    -> importa a la base BM
6) Abrir BM -> Terminal Restaurante -> Desayuno -> Historial
   o Administracion -> Inicio -> mes correspondiente

DATOS (orden de busqueda del .cmd)
----------------------------------
  1) ..\2-BM-DATOS\data\datos_hotel.json   (espejo D:\work)
  2) %LOCALAPPDATA%\BM-V2-local\...        (servidor)

Notas:
- Dias ya importados salen SKIP (no duplican).
- En PC con repo BM V.2 usa Python; en hotel usa BM-Launcher.exe.
